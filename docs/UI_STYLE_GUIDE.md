# ShopSphere --- UI Style Guide

## Design Goal

ShopSphere should look like a real, trustworthy small-business
storefront. It should not resemble an AI-generated SaaS template.

Backend engineering is the priority; the UI should be clean, solid and
functional.

## Color Palette

Primary: `#1F3A5F` --- Deep Slate Blue Background: `#F7F7F5` --- Warm
Off-White Surface: `#FFFFFF` Text: `#17202A` --- Charcoal Muted:
`#667085` Border: `#E5E7EB` Success: `#2F6B4F` Danger: `#B54747`

Use the primary color mainly for primary CTAs, active navigation, links
and focus states.

## Avoid

-   Purple/blue gradients
-   Neon colors
-   Glassmorphism
-   Glowing cards
-   Excessive rounded containers
-   Decorative blobs
-   Excessive animations
-   Huge marketing hero sections

## Typography

Use Inter or a neutral sans-serif.

Suggested scale: - H1: 32--40px - H2: 24--30px - H3: 18--22px - Body:
15--16px - Metadata: 13--14px

## Layout

-   Centered content container
-   Strong whitespace
-   Practical product grid
-   Responsive mobile layout
-   Clear checkout hierarchy

## Components

### Navbar

Store name/logo, search, categories, cart and account.

### Product Card

Image, name, price, discount if applicable, rating and clear CTA.

### Product Page

Image gallery, title, price, stock state, quantity, add-to-cart,
description and reviews.

### Checkout

Address, order summary, authoritative total, payment action and clear
states.

### Admin

Compact sidebar, data tables, filters, status badges and simple useful
charts.

## Animation

Only use functional transitions such as hover, loading, modal open/close
and success feedback.

## UX

Always support: - loading states - empty states - error states - success
feedback - disabled states - accessible labels - keyboard navigation -
useful validation messages
